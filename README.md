📊 Network Insight Agent

A LinkedIn Network Analysis Template powered by graph metrics and structural intelligence

Network Insight Agent is a lightweight browser-based template that helps users analyze their professional network using centrality metrics, clustering detection, tie-strength mapping, structural holes, and shortest-path intelligence — all from a simple LinkedIn connections export file.

Part of the JazzHQ AI Template Series.

✨ Features
📈 Network Visualization

Interactive force-directed graph showing relationships between organizations in your network.

🔢 Centrality Analysis

Automatically identifies:

high-influence clusters
bridging organizations
key connection hubs

using degree, betweenness, and closeness metrics.

🧠 Structural Intelligence

Detect:

structural holes
clustering coefficient
network density
average path length

to understand how information flows across your network.

🔗 Tie-Strength Mapping

Classifies relationships as:

Strong ties
Medium ties
Weak ties

based on connection recency.

🧭 Shortest Path Finder

Explore hidden relationship paths between organizations inside your network.

📊 Organization Deep Dive

See:

member distribution
influence weight
connection concentration
cross-cluster overlap

per organization.

🤖 AI-Generated Insights Panel

Automatically summarizes:

network structure
strongest clusters
bridging opportunities
growth signals

inside the dashboard.

🔐 Privacy First

Runs entirely in your browser.

No:

tracking
uploads
storage
external APIs
📂 Input Format

Export your LinkedIn connections:

Settings → Data Privacy → Get a copy of your data → Connections

Upload:

connections.csv

or

connections.xlsx
🚀 Getting Started

Clone the repository:

git clone https://github.com/Sasisampath/network-insight-agent-template.git

Open the file:

sociomap_pro_fixed.html

in your browser.

Upload your LinkedIn connections file.

Done ✅
